Kalau ada yang kirim undangan nikah dalam bentuk file APK, jangan langsung dibuka atau di-install. 🚨

Kenapa?

Karena APK adalah paket instalasi aplikasi Android, bukan format dokumen undangan seperti PDF atau gambar. File APK sendiri tidak otomatis berbahaya, tetapi APK yang datang tiba-tiba dari sumber yang tidak tepercaya adalah red flag besar.

🎯 Modusnya biasanya memanfaatkan social engineering:
• Nama file dibuat seperti undangan
• Konteksnya dibuat meyakinkan
• Korban dibuat penasaran
• Korban diarahkan untuk install aplikasi
• Setelah aplikasi berjalan, pelaku berharap mendapatkan akses atau memancing data sensitif sesuai kemampuan malware dan izin yang diberikan

⚠️ Penting: install APK tidak otomatis berarti rekening langsung terkuras. Dampaknya tergantung jenis aplikasi berbahaya, izin yang diberikan, kerentanan perangkat, tindakan korban, dan mekanisme penipuan yang digunakan.

Tapi risikonya bisa serius kalau korban kemudian memberikan akses atau data sensitif, misalnya kredensial akun, kode OTP, PIN, atau informasi finansial.

🛡️ Kalau dapat file seperti ini:
✅ Jangan install
✅ Jangan berikan izin aplikasi
✅ Jangan masukkan password, PIN, atau OTP
✅ Verifikasi identitas pengirim lewat kanal lain yang kamu percaya
✅ Kalau undangan memang asli, minta format dokumen/link resmi

😰 Kalau sudah terlanjur install:
• Jangan lanjutkan interaksi dengan aplikasinya
• Putuskan koneksi jika diperlukan
• Hapus aplikasi mencurigakan
• Periksa permission dan lakukan pemeriksaan keamanan perangkat
• Kalau sempat memasukkan kredensial atau data finansial, segera amankan akun melalui kanal resmi
• Pantau transaksi dan aktivitas akun untuk tanda-tanda mencurigakan

💡 Rumus gampangnya:
CHAT TAK TERDUGA + FILE APK + DISURUH INSTALL = JANGAN ASAL KLIK. 🚩

Undangannya boleh bikin penasaran. Tapi sebelum install apa pun, verifikasi dulu.
